# Carmonius Finsnickeri

36 statiska sidor för mobil och dator. Eget bildmaterial och bevarad originallogotyp. Sidor för tjänster, 25 möbler, detaljer, Ola, butik, kontakt och integritet.

## GitHub Pages
Ladda upp innehållet i mappen carmonius-github till ditt repository. Välj Settings → Pages → Deploy from a branch → main och / (root). Relativa länkar gör att även en projektsida fungerar.

Kontaktformuläret öppnar ett mejlutkast i besökarens mejlapp. Inget skickas eller sparas automatiskt. Butikens köpknapp går till den befintliga produktens ordinarie köpflöde. Kontrollera uppgifter och bildrättigheter med företaget inför offentlig lansering.

## Utveckling
Källan finns i scripts/build.py. Kör python3 scripts/build.py för att generera dist. CSS och JavaScript ligger i dist. Bilderna är lokala WebP-filer; typsnittet Manrope har medföljande licens.
